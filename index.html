BlobTrack Studio

A blob-tracking playground for live visuals.

Bright areas of the source become blobs. Each blob gets a stable track ID, then you decide how it is drawn, linked and labelled. Everything is composited in real time on the canvas, so what you see is what gets recorded.

Quick start

  1. Pick Camera, drop a video, or start with the built-in motion field.
  2. Adjust Threshold until only the interesting shapes are tracked. Track dark blobs flips the logic.
  3. Use Set ROI to restrict tracking to a region.
  4. Choose a look up top, then fine-tune shapes, links, labels and effects.
  5. Record for a manual take, or Export for a guided capture.
